# Online Food Ordering Application Automation Testing

## Project Overview
Automated functional testing of an online food ordering application using Selenium WebDriver and Java. The project focused on validating customer ordering workflows.

## Technologies & Tools
- Java
- Selenium WebDriver
- Cucumber
- Maven
- Page Object Model (POM)
- BDD (Behaviour Driven Development)

## Key Features
- Automated location selection and validation.
- Cucumber BDD-based test scenarios.
- Page Object Model for maintainable test scripts.
- Test execution reporting.

## My Contribution
Completed as part of an internship at Fortray. My primary contribution was automating the collection/delivery location selection flow and its associated validations using Selenium WebDriver.

## How to Run
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Ensure Java and Maven are installed.
4. Run the following command:

```bash
mvn clean test
```
